开播流程（详细版）
选游戏
进「游戏库」，搜索或浏览找到要播的游戏，点一下卡片选中（右上角出现「✓已选」）。
打开游戏并开自动
卡片点「打开」→ 游戏在独立窗口弹出。先看窗口顶部「配置说明」：里面有这款游戏怎么开启自动玩的具体步骤，照做即可；看完可点「配置」收起。
保持屏幕常亮
游戏窗口打开后自动开启「屏幕常亮」（标题栏绿色「常亮·开」），游戏一直亮屏运行；直播期间不要点「✕」关闭游戏窗口。
拉起直播APP
回到本页点「抖音开播 / 快手开播 / 视频号开播」拉起APP → 选「游戏直播 / 屏幕采集」→ 把手机屏幕（游戏画面）采集进直播间，并确认「收录系统声音」打开。
切回游戏窗口
回游戏窗口让游戏在前台继续跑，直播画面就是游戏画面；期间可随时点悬浮球或回本页操作盒子。
开语音播报
回本页打开「语音播报」四个开关（自动解说/报时/欢迎/守护），去「语音」页选音色、调语速音量音调、设播报频率并保存，再回来点「试听一句」确认有声音。
开防封并看状态
「防封」页一键全部开启；回「开播」页看「播报状态」：绿灯闪动、显示最近播报内容，说明解说/报时/欢迎正在按频率自动出声。

怎么添加到主屏幕（桌面图标）
步骤 1 · 浏览器打开
微信/QQ 里点开收到的链接或文件 → 右上角「···」→ 选「用浏览器打开」；或复制链接直接粘贴到浏览器打开。
步骤 2 · 添加到主屏幕
在浏览器里点「分享」按钮 → 选「添加到主屏幕」→ 命名（如：智播游戏盒）→ 点「添加」。
步骤 3 · 以后这样用
手机桌面出现「智播游戏盒」图标 → 点图标直接打开使用，不用再找链接。
使用提示 · 各模块流程
① 首次使用（激活）
打开页面 → 自动进入授权页 → 本机机器码自动生成 → 把机器码发给管理员 → 输入管理员发的授权码 → 点「激活」→ 顶部出现「已授权·永久」即成功 → 刷新/重开免授权。
② 游戏库：打开游戏
浏览或搜索 141 款游戏 → 点卡片上的「打开游戏」→ 游戏在独立窗口打开，顶部标题栏自动隐藏，画面纯净无杂物，可直接供直播采集。
③ 游戏窗口右上角「•••」三点钮
点一下呼出工具栏（6 秒后自动收起，收起后小钮自动回来，不会和关闭键重叠）。工具栏里 5 个按钮：
· 配置：查看当前游戏玩法/如何开启自动玩；
· 常亮：开=屏幕保持常亮不熄屏（直播建议开）；关=恢复自动息屏；
· 刷新：游戏卡住/白屏时点它重新加载；
· ─ 最小化：游戏缩到右下角悬浮球，后台继续运行（回盒子操作其他页不打断）；
· ✕ 关闭：彻底关掉当前游戏，恢复主界面。
游戏没声音？轻点游戏画面即可激活声音（手机系统限制，正常现象）。
④ 开播：完整直播流程
第1步：游戏库打开游戏 → 点「─」最小化到右下角悬浮球；
第2步：进「开播」页，四个语音开关（自动解说/自动报时/欢迎语/人声守护）全部保持开启；
第3步：点「抖音开播 / 快手开播 / 视频号开播」拉起直播APP；
第4步：在直播APP里选「游戏直播 / 屏幕采集」，采集游戏画面（窗口已是纯净全屏，无需裁剪）；
第5步：在直播APP的设置里打开「收录系统声音 / 麦克风」，播报声音才会进直播间；
第6步：回到盒子，点右下角悬浮球把游戏恢复出来，一直播。
「播报状态」区绿灯闪动、显示最近播报内容 = 解说/报时正在按频率自动出声。
⑤ 语音设置
· 音色：内置 10 个（小帅/小美/婷婷/美佳/大壮/阿浩/朵朵/阿泽/宁宁/大宇）。安卓会自动切换男女真声；iPhone 系统只有一个中文声，网页无法造出多个真音色（手机系统限制，任何网页工具都一样）；
· 语速/音量/音调：拖动滑块即时生效，实时应用，不用重启；
· 试听：点「试听」直接读当前音色名（如“我是小美，女声活泼音色”）确认切换生效；
· 播报频率：解说间隔/报时间隔/欢迎守护间隔按秒填 → 点「保存频率」→ 报时按设定秒数准点触发，设定几分钟就是几分钟；
· 电脑版音色服务（可选，有电脑的学员）：电脑上开着「智播·电脑版」时，填电脑地址（IP:端口）→ 开启 → 10 个音色变成真男女声（与电脑版完全一致），连不上自动回退手机语音，不影响其他功能。
⑥ 防封（一键防封）
进「防封」页点「一键全部开启」，28 项全部变绿生效（不是摆设）：
· 真人化：播报间隔随机不像机器、话术去重不连续重复、口语化、随机停顿/语气词、语速音量微扰、回复延迟；
· 话术兜底：AI 智能生成优先，生成不了自动用话术库，话术库空再用内置兜底句；
· 敏感词管理：播报开口前自动过滤，内置 30+ 词（微信→联系方式、加我→可以找我、红包→小红包、提现/赌博/涉黄/最好/顶级/全网等自动删除）；页面下方可输入自定义词「添加」，可随时「删除」，即存即用。
⑦ 话术库
欢迎语/解说词/播报话术/守护话术/报时话术 5 个分类，每类内置话术可「测听 / 改 / 删」；底部「＋新增自定义」添加自己的话术；自动解说、报时、欢迎/守护实时使用话术库内容，改完即生效。
⑧ 报时
自动报时开口先报「现在北京时间 X点X分」再带一句唠嗑话术；报时话术里的 {now} 占位自动替换成当前时间；间隔按语音页「报时间隔」设定，准点触发，一秒不差。
